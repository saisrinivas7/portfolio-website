A multi-agent system for claims adjudication on Vertex AI, in a HIPAA environment. My part is retrieval and evaluation.

  • Built the eval harness — a golden dataset and LLM-as-judge checks that run before changes ship. Hallucination rate sits under 2%.

  • Built a natural-language query agent on Google ADK against MongoDB and BigQuery, answering in plain English with citations back to source.
  • Work on the ETL underneath it — Airflow and Dataflow on GCP, around a million records a week.
